# 本機網頁工作台

v0.7.0 預設從 `WardLens.exe` 開啟「查房前整理」與「急症處置」。網頁由同一台電腦的 WardLens 提供，隨包附上全部畫面資源；不用安裝 Node、pip 或 WebDriver。登入與資料擷取沿用既有 Requests 流程。

## 開啟、重開、結束

1. 將 `WardLens-Portable.zip` 完整解壓縮，雙擊 `WardLens.exe`。EXE、`runtime`、`app`、`packages` 必須一起保留。
2. 小控制視窗出現後，Windows 優先用 Edge InPrivate 開啟工作台；不可用時嘗試預設瀏覽器。第一次先以合成 Demo 登入並載入 18 人清單。
3. 控制視窗可最小化。網頁沒有開啟、被關閉或重新整理後，按控制視窗的「開啟工作台」重新連線。
4. 結束時按控制視窗「結束」、關閉控制視窗，或按網頁「結束 WardLens」。只關網頁不等於停止服務。

重新整理需要重開，是因為本次連線憑證只留記憶體，不存進瀏覽器；不要把網址當書籤或分享。重開可讀取尚在程式記憶體的狀態，但不要依賴重新整理來保存尚未同步的輸入。

需要舊版桌面介面時，按「切換桌面備援」、執行 `Start-WardLens-Desktop.bat`，或使用 `WardLens.exe --desktop`。切換會關閉本次網頁工作階段，病歷草稿與回答不會搬移；本機 API key、模型與 prompt 設定仍沿用。

## 查房前整理

登入後以醫師燈號／病房載入清單，選病人，再按「載入 / 更新資料」。回溯預設三個月，改選 1／3／6／12 個月後要重新載入；選項不會改寫已取得的快照。

總覽先看 TODO、生命徵象、用藥、報告與趨勢。CBC 優先 WBC／Hb／PLT，differential 收合。表格由原始資料直接整理，不需 AI；每列保留最近一次量測時間與跨度，詳細值／時間／來源可以展開。

未知時間另列，不接在最新值後面；不同單位分開；同時間不同結果會保留矛盾。只有一筆不能判定趨勢，缺時間／單位或無法安全比較時不畫曲線。迷你圖僅連接已取得的觀測點，不代表空窗期間有量測。缺資料、未載入或截短都不代表正常。

## 資料、問題與回答

兩個工作區各有獨立草稿。展開「編輯病人資料」可刪改本次 AI input；下方問題框填想追蹤的事，急症頁則填目前病況、已做處置與反應。清空資料框後不會另外附回隱藏病歷。重新載入或切換病人前，先處理要保留的草稿。

查房頁可選查房整理、Admission Note 或自由提問。按「預覽並送出」，核對去識別內容、本次模型與必要確認，再按「確認送出」。背景 prompt 與完整 input 平時收合；若被疑似識別碼擋下，在修正框遮罩並重新檢查。預覽不是日常資料編輯框。

回答顯示 Markdown 標題、清單及表格；「複製純文字」方便貼入其他系統，「Markdown 原文」可核對原回答。「複製給其他 AI」複製經預覽的完整 input。瀏覽器不允許自動複製時，會提供文字框讓你按 Ctrl+C。剪貼簿可能同步到其他裝置；60 秒後的條件清除可能受瀏覽器權限阻擋。

內建查房回答不反覆列 SRC／hash／D±日碼，但仍保留重要時間間隔、資料過舊與矛盾。急症維持先處理危急生理問題；有立即危險先叫支援，不等 AI。英文 Admission Note 保留六章節與敘事式 HPI，不把缺漏補成事實。

## 設定與升級

「設定」可登入 OpenRouter，或貼上一次 API key 後儲存到 Windows Credential Manager。啟用開發者模式並儲存，再按「開啟編輯器」，可改模型 ID、reasoning、輸出額度及四套 prompt。Max tokens 留白或 0 使用供應商預設，仍可能達供應商上限。

升級會保留自訂模型與 prompt；新版精簡內建文字不會覆蓋你的版本。自訂 prompt 若仍要求 SRC 或 D 碼，請在編輯器自行修改。Prompt 會存入本機設定與設定匯出檔，勿填病歷、密碼或 API key。

「登出清除」清掉本次病人資料、問題與回答；結束程式也會清掉記憶體狀態。程式不把臨床內容寫入網頁儲存空間或一般 log，但手動匯出、複製及使用者自行保存的檔案仍會存在。`no-store`／InPrivate 不保證瀏覽器、擴充功能或作業系統絕不留痕。

資料送往 OpenRouter 仍是外部處理；本機網頁不會改變這個邊界。預覽、修正與每次確認持續適用。更多細節見 [AI 與趨勢](AI_AND_TRENDS.md)；獨立 [瀏覽器測試](BROWSER_TEST.md) 並不是使用主介面的必要步驟。

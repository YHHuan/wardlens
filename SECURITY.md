# Security policy

WardLens handles highly sensitive clinical data. Do not open a public issue containing patient data, credentials, cookies, HTML, screenshots, prompts or model responses.

For a vulnerability report, provide the affected version, reproduction using synthetic data, expected impact and any proposed mitigation through a private GitHub security advisory. Revoke exposed credentials immediately and follow the hospital incident-response process.

Supported line: the latest tagged release only. Use only the complete `WardLens-Portable.zip` asset whose SHA-256 matches the same Release's `SHA256SUMS.txt`; do not redistribute individual runtime files or launchers. This MVP has not completed an independent penetration test or a VGH production pilot.
